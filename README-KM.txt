# TOOLS WEI V FULL — GitHub Pages

## របៀបដាក់ Website លើ GitHub (Android)

1. មុនប្តូរទៅ Website ថ្មី សូមបើក Tools Wei ចាស់ ហើយចុច **Save Backup to Phone**។ រក្សាទុកឯកសារ JSON ក្នុង Downloads។
2. បើក https://github.com ហើយ Sign in។
3. បង្កើត repository ថ្មី ឈ្មោះ `tools-wei`។ ជ្រើស **Public** ហើយចុច Create repository។
4. នៅក្នុង repository ចុច **Add file → Upload files**។
5. Upload ឯកសារទាំងអស់នៅក្នុង ZIP នេះ ដោយ Upload `index.html`, `manifest.webmanifest`, `sw.js` និងថត `icons` (កុំ upload ZIP តែមួយ)។
6. ចុច **Commit changes**។
7. ចូល **Settings → Pages**។
8. ក្នុង **Build and deployment** ជ្រើស **Deploy from a branch**។
9. ជ្រើស Branch `main` និង folder `/ (root)` រួចចុច **Save**។
10. រង់ចាំ GitHub បង្ហាញ Website URL ជាទម្រង់ `https://YOUR-USERNAME.github.io/tools-wei/`។
11. បើក URL នោះក្នុង Chrome។ Restore JSON backup ដែលបានរក្សាទុកពីមុន។

## Add to Home Screen (Android)

- បើក Website ក្នុង Chrome។
- ចុចម៉ឺនុយ ⋮ → **Install app** ឬ **Add to Home screen**។
- បន្ទាប់មកបើក Tools Wei ពី Icon លើ Home Screen។

## ការរក្សាទុកទិន្នន័យ

- ទិន្នន័យប្រតិបត្តិការរក្សាទុកក្នុង Browser របស់ឧបករណ៍នេះ។
- ចុច **Save Backup to Phone** ក្នុង Settings ដើម្បីទាញយក JSON។
- បើក Google Drive → `+` → Upload → ជ្រើសឯកសារ JSON ក្នុង Downloads។
- ពេលប្ដូរទូរស័ព្ទ ឬ Browser៖ Download JSON ពី Drive ហើយប្រើ **Restore Backup**។
- GitHub Pages បង្ហោះតែ App files; វាមិន Sync ឬរក្សាទុកទិន្នន័យអាជីវកម្មទៅ Drive ដោយស្វ័យប្រវត្តិទេ។
- Offline mode ដំណើរការបន្ទាប់ពី Website ត្រូវបានបើក និង cache បានជោគជ័យម្តង។
- កុំលុប Browser data មុនពេល Backup។

## ចំណាំសុវត្ថិភាព

ការប្រើ GitHub Pages តម្រូវឱ្យ repository ជា Public នៅលើគណនី Free។ កុំដាក់ឯកសារ Backup JSON មានទិន្នន័យអាជីវកម្មនៅក្នុង GitHub repository។
